# Demo photos

These two synthetic sample photos were generated with the built-in imagegen tool
for this learning project. The people, captions and reaction counts in the UI are
fictional sample content. Images are bundled locally; no remote image service is used.

- `coastal-cove.webp` (1200 × 800): quiet Mediterranean limestone cove, clear
  turquoise water, a pine tree and warm afternoon light; natural editorial photo,
  full-frame landscape composition, no people, text, logos or collage.
- `morning-coffee.webp` (1200 × 800): cream ceramic coffee cup, blank notebook and
  a glass vase with a leafy branch on an oak café table; soft morning window light,
  natural editorial photo, full-frame landscape composition, no people or text.

These descriptions record the generation prompts. Generated PNG originals were
resized to WebP for the app; both files reserve a 3:2 aspect ratio.
